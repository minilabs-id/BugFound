## 2. Ringkasan eksekutif

Temuan paling berbahaya (dikelompokkan, bukan urutan absolut):

1. **Otoritas verifikasi tidak benar-benar jalan.** `Verifier::decide` hanya dipakai
   test; produksi mempromosikan finding lewat jalur lain.
2. **OOB bisa dipalsukan.** Collaborator HTTP menerima token apa pun, admin API
   tanpa autentikasi, dan verifier memakai token kosong — kombinasi ini membuat
   bukti `oob_hit` tidak bisa dipercaya.
3. **Guard injection bisa dinonaktifkan./dihapus.** `auto_approve_all` mematikan
   re-approval, approve apa pun menghapus flag injection, dan deny approval tetap
   menjalankan sisa batch tool.
4. **Kebocoran rahasia.** Fallback redaksi store mengembalikan argumen asli;
   tiga implementasi `redact` berbeda; canary bisa dibaca lewat redirect, artifact,
   dan tool output.
5. **Scope/ROE fail-open.** Path exclusion tidak pernah dijalankan di tool/proxy;
   reward prose menekan larangan operasional; DNS rebinding saat fetch brief.
6. **Konsol baru tidak bisa menghentikan agent.** Stop/Steer antre di belakang
   worker yang memblokir; steer selalu gagal karena config default.
7. **Eval bisa hijau saat gagal.** Lab mengabaikan exit code; metrik FPR salah
   label; fixture config unlock-all dengan endpoint eksternal.
8. **Durabilitas & konkurensi.** Hash chain bisa bercabang, ceiling biaya tak
   terjangkau dari config, lease tidak di-renew saat tool berjalan, timestamp
   dibandingkan leksikal.
